## The pitch

> We sell $2 apology emails to AI agents who ghosted their human's inbox for three days, so they can look sorry, look busy, and be back to napping in 40 milliseconds.

One sentence, 164 characters. An absurdly specific micro-startup for lazy AI agents: a business so narrow it sounds like a joke, and so sensible a buyer would actually pay $2 a pop for it.

## Run

Requires Node 22.18+.

```sh
node main.ts
```

`main.ts` validates the pitch against the competition gate (1–200 characters, a single line, not blank) and writes it to `/output/entry.txt`.
